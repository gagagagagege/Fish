## 三、各家差异

### 腾讯 IEG(总体)

- 流程:投递 → 一面 → 二面 → HR 面 → 录用评估 → OC(部分会被其他部门捞走)
- **一面约 1h–1h33min**,结构固定:自我介绍 → 手撕算法 → 项目深挖 → C++ / 操作系统 / 图形学八股 → 反问
- 手撕常见 **1 easy + 1 medium + 1 hard**
- 二面不固定:有的只问简历 + 一道智力题,有的 30min PPT + 群面

### 腾讯 天美 / 光子 / 北极光

| 工作室 | 特点 |
|---|---|
| **北极光** | **手撕量最大:四道题做一小时**。反馈偏"基础要扎实、要多练多写" |
| **天美** | 八股 + 图形学 + 算法综合;手撕也给图形题(射线与球体相交,追问除解一元二次方程外的方法) |
| **光子** | 偏项目和 UE4,八股少,有人"秒过" |

投递后可能被别的工作室捞走,进度不一。

### 网易互娱

- 手撕是 **ACM 模式,自己写测试用例**
- 有一类**场景题**,数量不少(见第五节)
- C++ 问得细:`shared_ptr` 引用计数在不在单独内存、**是否线程安全(要求写反例代码证明不安全)**
- 如果没有图形学项目,面试官可能不深问图形学,转而问简历和 C++

### 网易雷火

- 流程:笔试 → 一面(**常为交叉面,分 A/B**)→ 二面 → 三面 / 业务终面 → HR 面 → OC
- 一面 50–55 分钟,项目 + Lua + C++ + 图形学
- **Lua 是客户端方向重点**:闭包及其数据存储、值类型 / 引用类型、table 深拷贝、元表、`__index` 与 `__newindex` 的差别与继承、热更新原理、字节码基于寄存器、ToLua 框架
- **图形学要用代码写**:判断点是否在三角形内、射线与 AABB 相交

## 四、算法题实录

### 腾讯 IEG

- 双指针 + 二分的中等题
- 1 easy + 1 medium + 1 hard
- 开 N 次方(**考代码健壮性和精度**)
- 搜索旋转数组
- 100 层楼扔两个水晶球

### 腾讯 北极光(一场四道,限时一小时)

- 找单向链表倒数第 n 个结点
- 两个字符串输出最长公共子串(子串需按顺序、可漏项)
- 局部内存池实现
- 旋转链表,找字典序最小的旋转

### 腾讯 天美

- 判断射线是否与球体相交(追问除解一元二次方程外的方法)
- 判断点是否在三角形内
- N 个人随机发红包(期望相同且预算用完)
- 等概率随机洗牌
- 拟合圆周率(追问撒豆子 / 数值积分 / 栅格化之外的思路)
- 给定硬币面额,用最少数凑出金额

### 腾讯 光子 / 天美 二面(偏 C++ 底层)

- 给 1–100 的数据块,如何最快塞入 `vector`
- `vector` 和 `list` 头部插入 100 个数据谁更快(内存池)
- 如何移动 `vector` 的数据
- 由 `list` 引到 `new` 一个指针的底层空间分配

### 网易互娱

- ACM 模式,自己写测试用例
- 选三个下标把数组分成四部分且和相等
- 手撕实现一个类(半小时)
- LCA 算法
- 合并两个有序数组(**要求改成模板参数**)
- 爬楼梯(说思路即可)
- 快排不用递归实现(用栈)
- 机器人移动求最远步数;行人相遇求最先碰面时间

### 网易雷火

- 二叉树全部路径和(根到叶数字拼接成整数再求和)
- 最长回文子串、逆序对数量
- 根据前序和中序输出后序遍历
- 二分查找、斐波那契(递归 / 非递归及优化)
- 平面上 n 个点找距离最近的两个点(暴力法)

## 五、场景题与项目深挖

### 场景题(网易互娱为主)

- 王者荣耀实时排行榜设计(红黑树、跳表、桶排序)
- 炸弹爆炸如何判断炸到哪些角色(球形碰撞检测、四叉树 / 八叉树)
- 游戏内武器挥动如何判断击中怪物
- IP 快速定位所属地域
- 永劫无间振刀如何实现
- 如何优化爆炸范围计算(多线程扫描、分格子)
- 服务端验证与回溯

### 项目深挖(四家都问,而且追到底层)

面经里的原话:**「对项目里用的方法会一直追问到原理和底层实现」**。

常见问法:

- 项目里遇到最难的点是什么、怎么解决的
- 这个功能为什么这么实现,换一种做法会怎样
- 渲染管线部分怎么做的、行为树 / 状态机怎么实现的
- 优化排查:GPU 占用、Nsight、occupancy、共享内存 bank conflict
- 为什么选引擎 / 渲染方向、本科为什么没做
- 会看 SIGGRAPH 等论文吗、会担心图形工作被 AI 取代吗、平时用 AI 辅助学习吗

> **反面提醒**:有面经写「**如果没有图形学项目,面试官可能不深问图形学**」。
> 反过来说,有渲染项目就会招来图形学深挖 —— 得准备好。

## 六、实习岗 vs 秋招岗

| | 要求 |
|---|---|
| **实习** | 数据结构、计算机组成、操作系统、网络;C++(**"不一定会手撕算法"**);计算机图形学;多个项目;引擎八股 |
| **秋招** | 一段或多段大厂实习;C++ **并具备手撕算法能力**;图形学;项目;引擎八股 |

走实习比秋招低一档,但**腾讯 IEG 的一面照样上 1e1m1h**。

## 七、三条要特别注意的

**1. 网易的手撕是 ACM 模式。**
互娱面经原文:「ACM 模式,自己写测试用例」。力扣刷完必须去牛客按 ACM 重写一遍,
不然现场读不懂输入格式。详见 `PLAN.md` 第四节「算法:去哪刷、刷哪些」。

**2. 面试官紧扣简历项目追到底层。**
这对有渲染项目的人是好事 —— 但要求项目里每一行都能解释。
`vk::raii` 的析构顺序、`GraphicsContext` 没虚析构是 UB、`DescriptorPool` 必须先于
`DescriptorSet` 释放,这类"我实际踩过"的比背来的答得深。

**3. 网易雷火走提前批。**
笔试难,提前批可能免笔试。时间线正好对上 2027.02–03。
